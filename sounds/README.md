# Dashboard-Sounds

- `bowling-strike.mp3`: „Bowling Strike“ von SieuAmThanh, Freesound #514385, 21.04.2020. Reale Aufnahme eines Kugel-/Kegeltreffers. Quelle: https://freesound.org/people/SieuAmThanh/sounds/514385/ — CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/ . Verwendet wird die MP3-Vorschau der Quelle (ca. 1,4 Sekunden). Die Quellbeschreibung verweist auf kyles' „bowling-alley-pins-serving-mechanism2“.
- `zonk.mp3`: für dieses Projekt synthetisch erzeugter vierstufiger, fallender Blechbläser-/Zonk-Effekt (ca. 2,5 Sekunden). Keine Aufnahme einer Fernsehsendung. Unter CC0 1.0 zur freien Verwendung bereitgestellt.

Die beiden Effekte werden ausschließlich im Dashboard nach dem Aktivieren von „Ton an“ abgespielt. 9er, Kranz und Durchgeworfen lösen den Kegeltreffer aus; Gosse löst den Zonk-Effekt aus. Die letzten zehn Countdown-Sekunden ticken, bei Ablauf folgt das Endsignal. Alte oder erneut empfangene Ereignisse werden nicht nachträglich vertont.
